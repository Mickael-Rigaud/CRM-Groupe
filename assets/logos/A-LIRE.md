# Logos des structures

Déposer ici le logo de chaque activité, nommé exactement d'après sa clé
(`js/data/schema.js`) :

| Fichier                  | Structure              |
|--------------------------|------------------------|
| `rgd.png`                | RGD Renova             |
| `btp.png`                | BTP Expertise          |
| `courtage.png`           | La Référence Courtage  |
| `propulsion.png`         | Propulsion             |

Format : PNG à fond transparent ou blanc, carré, 96 × 96 px minimum.
Le logo s'affiche dans un carré de 20 px : préférer le **pictogramme seul**
(sans le nom écrit), sinon il sera illisible à cette taille.

Un fichier absent n'est pas une erreur : la pastille de couleur de l'activité
s'affiche à la place.
